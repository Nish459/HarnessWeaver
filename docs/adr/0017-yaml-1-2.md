# ADR-0017: Specs are YAML 1.2 (core schema)

**Status:** Accepted

## Decision

Specs are read as YAML 1.2 (core schema): only `true`/`false` are booleans, there are no implicit dates or sexagesimal numbers, `012` is decimal, and duplicate keys are errors.

## Why

PyYAML implements YAML 1.1 (`no` is false, `1:30` is 90), while JavaScript's `yaml` follows 1.2. One schema keeps a spec meaning the same in every language.
